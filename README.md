# Homebrew Tap for SKey

Official Homebrew Cask tap for [SKey](https://github.com/Nam088/skey) — Modern Vietnamese Input Method Engine for macOS.

## Installation

```bash
brew install --cask nam088/tap/skey
```

Or tap first:

```bash
brew tap nam088/tap
brew install --cask skey
```

## Update

```bash
brew upgrade --cask skey
```

## Uninstall

```bash
brew uninstall --cask skey
```
